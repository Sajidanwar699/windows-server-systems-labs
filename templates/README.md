# Adding a new lab

1. Pick the section folder (or create a new one, for example `dns-dhcp/`).
2. Copy `templates/lab-template` into the section as `lab-NN-short-name/` (use the next number in that section: `lab-02-...`, `lab-03-...`).
3. Put screenshots in the lab's `images/` folder, named `01-step-1.png`, `02-step-2.png`, and so on.
4. Add the lab to the section's `README.md` table and to the main `README.md`.
5. Update the previous lab's "Next" link.

Rules: each section numbers its own labs from 1. Lab folders never move or get renumbered, so links stay stable.
